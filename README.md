# 📋 Project Overview

Ascent is a modern frontend website interface developed for educational institutions such as kindergartens and primary schools.

The project focuses on creating an engaging and user-friendly experience with responsive layouts, smooth animations, interactive components, and modern UI design.

The website helps schools showcase:

* Educational programs
* School services
* Learning activities
* Information for parents
* School introduction content

---

# 🚀 Key Features

## 🎨 Modern UI Design

* Responsive design across devices
* Clean and professional educational interface
* Modern layouts using Tailwind CSS

## ✨ Interactive Experience

* Smooth animations with Animate.css
* Scroll-based animations using WOW.js
* Interactive sliders with Swiper.js

## 📱 Responsive Design

* Desktop optimization
* Tablet compatibility
* Mobile-friendly interface

## 🏫 Educational Content

* School introduction
* Curriculum presentation
* Services information
* Student activities showcase

# 📦 Prerequisites

Before running the project, make sure you have:

* Node.js (v16+ recommended)
* npm (Node Package Manager)

---

# 🔧 Installation

## 1. Clone Repository

```bash id="gq2n8m"
git clone https://github.com/vuth9808/ascent2.git

cd ascent2
```

---

## 2. Install Dependencies

```bash id="zq4h1k"
npm install
```

---

## 3. Run Project

Open:

```text id="d7h3wp"
index.html
```

or use:

* VS Code Live Server Extension
* Open in Default Browser
